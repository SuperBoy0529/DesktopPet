## 常见追问的准备答案

**Q：为什么下载下来和视频里不一样？**
A：视频演示用的是我本地自备的素材；公开版本用自绘素材，避免分发版权素材。仓库 README 第 13 节写了怎么换成你自己的图。

**Q：能提供素材包吗？**
A：不能。分发游戏美术资源属于侵权，所以仓库里既不提供也不放链接。你可以用自己合法持有的资源，脚本会自动处理抠底和缩放。

**Q：会被告吗？**
A：本项目代码 MIT、不含第三方素材，展示层面属于同人二创。是否有风险由使用场景决定，请自行判断。
